# Java Calculator

A menu-driven command-line calculator built in Java. This beginner-friendly project demonstrates object-oriented Java fundamentals, methods, loops, switch expressions, collections, and input validation.

## Features

- Addition, subtraction, multiplication, and division
- Powers and square roots
- Calculation history
- Clear-history option
- Protection against division by zero
- Validation for incorrect user input

## Requirements

- Java Development Kit (JDK) 17 or newer
- VS Code with the **Extension Pack for Java**

## Run in VS Code

1. Open the `java-calculator` folder in VS Code.
2. Open `src/Calculator.java`.
3. Click **Run** above the `main` method.

You can also use the terminal:

```bash
javac -d out src/Calculator.java
java -cp out Calculator
```

## Example

```text
Choose an option: 1
Enter the first number: 10
Enter the second number: 5
Result: 10.0 + 5.0 = 15.0
```
